# Fighting Character Select

An Unreal Engine 5.8 source plugin for customizable fighting-game character selection screens, with a visual Slate editor called **Character Selection Studio**.

Includes rosters, grid/linear navigation, local two-player and CPU selection, keyboard/controller joining, 2D/3D previews, animations, themes and match handoff. Your game supplies combat and gameplay controls.

## Get started

1. Copy this folder into your project's `Plugins` folder, enable **Fighting Character Select**, and compile/restart the editor. Source builds need a compatible C++ toolchain.
2. Open **Tools > Character Selection > Character Selection Studio**.
3. Choose **New setup**, add characters, save, and place the generated launcher in your level.
4. Open **Studio Guide** in the toolbar for short walkthroughs.

The guide opens automatically on first editor startup per user/project. The plugin does not include the host project's demo artwork. Precompiled releases must match your Unreal version and platform.
