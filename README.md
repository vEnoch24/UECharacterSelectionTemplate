# Character Selection Studio

An Unreal Engine 5.8 plugin and demo project for building character selection screens for 2D and 3D fighting games.

Customize your roster, layout, portraits, 3D previews, animations and controls in a visual Studio. Supports local two-player joining, keyboard/controller input and CPU opponent selection.

**Open Studio:** Tools > Character Selection > Character Selection Studio.

Choose **New setup** to create a screen, or select your existing launcher in **Setup**. Open **Studio Guide** in the toolbar for short walkthroughs, then save your changes and test in Play.

The project handles character selection and passes the choices to your game. Your game supplies combat, fighter spawning and gameplay controls.

Plugin installation: [Fighting Character Select](Plugins/FightingCharacterSelect/README.md).
