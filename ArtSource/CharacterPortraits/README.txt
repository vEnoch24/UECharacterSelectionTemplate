ORIGINAL CHARACTER PORTRAITS

Each fighter has two transparent PNG files:
  <Name>_Slot.png  - close-up artwork for character grid slots
  <Name>_Large.png - full-body action artwork for player previews

Created with Codex's built-in image-generation tool. The large illustrations
use new designs; slot portraits use the corresponding large image as reference.
Generation prompts and source filenames are recorded in manifest.json.

Existing fighters: Drexter, Emma, Galatea, Zain, Mary, Ella, Saturn, Mark, Adeyemi.
Mark's asset filename remains Mark5 to preserve existing project references.
New fighters: Nia (Ice User) and Kofi (Sound User).

In Unreal's Content Browser, textures are under:
  /Game/CharacterSelect/UI/Textures/OriginalRoster
Character data assets are under:
  /Game/CharacterSelect/Data/Characters
Open a character data asset to change Portrait or Large Portrait.

The two new fighters are presentation/selection examples. They do not include
new playable character Blueprints, skeletal meshes, or gameplay abilities.

Original edited data assets are backed up under Saved/PortraitBackup.
Existing UI animation assets are not modified by this artwork update.
